# AIMA Norte — vitrine conceitual

Protótipo de catálogo responsivo construído a partir das quatro fichas de modelos enviadas no Instagram da AIMA Norte. Nomes, fotos e especificações reproduzem o material recebido; disponibilidade, versão, garantia e todos os dados comerciais devem ser confirmados pela concessionária. Endereço e WhatsApp vieram dos canais públicos já registrados no relatório de prospecção.

## Abrir localmente

Abra `index.html` no navegador. A prancha de apresentação está em `arte/prancha.html`.

## O que a prévia demonstra

- Vitrine mobile first com quatro fichas sem repetição: Luna Bliss, Liberty, Q5 Dimoon e Mini Kuyan.
- Busca, categorias, detalhes em modal e CTA contextual para consultar cada modelo.
- Localização, link ao Google Maps e contato de WhatsApp.
- Prancha ilustrativa com notebook, tablet e celular.

Não inclui checkout, confirmação de estoque nem painel administrativo de produção.
